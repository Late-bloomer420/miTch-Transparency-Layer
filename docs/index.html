Privacy Policy for miTch Transparency Layer

miTch Transparency Layer is a browser extension that helps users understand browser-visible website behavior.

Data Processing

The extension analyzes information that is visible inside the user's browser, including:

  • current website domain and page title
  • cookies associated with the current website
  • localStorage and sessionStorage usage
  • browser-visible network requests
  • browser permission states
  • fingerprinting-related browser surfaces such as Canvas, WebGL, AudioContext, and WebRTC

Local Processing Only

All analysis is performed locally in the user's browser.

miTch Transparency Layer does not operate a backend server, does not create user accounts, and does not transmit analyzed data to the developer or to any third party.

No Sale or Sharing of Data

miTch Transparency Layer does not sell, share, or transfer user data to third parties.

No Remote Code

The extension does not use remote code. All extension code is packaged with the extension.

Limitations

miTch Transparency Layer only reports browser-visible behavior and technical capability. It does not claim what a website stores on its servers, how long data is retained, whether data is sold, or whether internal profiling occurs.

Contact

For questions, contact the publisher through the Chrome Web Store listing or the linked GitHub repository.
