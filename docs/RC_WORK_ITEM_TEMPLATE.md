# Work item and PR template

## Work item
- **Problem and user outcome:**
- **Scope / non-goals:**
- **Source and current evidence:**
- **Dependencies and decision ADR:**
- **Acceptance criteria:** observable, testable checkboxes, including failure and privacy boundaries.
- **Verification:** commands, environment, expected results, exact revision and artifacts.
- **Risks / known unknowns:**
- **Traceability:** suggested branch; actual branch/PR/commit links added when they exist. Never imply a planned branch was created.

## PR description
- **Problem and result:**
- **Refs:** issue and decision draft (use `Refs` until all acceptance criteria are met).
- **Changes and scope:**
- **Verification:** commands, real browser and environment, outcomes, CI links.
- **Privacy, compatibility, licensing and limitations:**
- **Follow-up:** remaining gates, rollback and evidence gaps.

## ADR
- Status: proposed / accepted / superseded, date, owner and reviewer.
- Context, decision drivers and alternatives (including no change).
- Evidence, proposed decision, consequences, privacy and security impact.
- Adoption gates, verification, rollback, links to issue, PR and exact revision.
